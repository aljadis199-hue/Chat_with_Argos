Esta página necesita un servidor

Tienes tres formas de abrirla bien:

  1. Publicada en GitHub Pages — la más cómoda para compartir. Abre la dirección https://tu-usuario.github.io/document-ai-web/
  2. Doble clic en servir.bat (en esta misma carpeta). Levanta un servidor local y abre el navegador solo. Requiere Python.
  3. A mano, desde una terminal en esta carpeta: 
    python -m http.server 8080
    y luego abre http://localhost:8080

Servida localmente además funciona Ollama, que en GitHub Pages queda bloqueado por ser una página HTTPS llamando a localhost.
